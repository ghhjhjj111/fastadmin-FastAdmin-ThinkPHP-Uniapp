# fastadmin沃德商协会管理系统源码 FastAdmin+ThinkPHP+Uniapp

源码获取：ym7k.com/19777/

## 📦 核心功能模块

### 1. 会员 & 会费管理（核心）

- 在线入会申请：个人会员 / 企业会员 / 团体会员，**自定义入会表单字段、附件上传**
- 四种入会模式：线上缴费入会、线下缴费凭证上传审核、后台批量导入、0 元免费入会
- 会费规则：**按入会周年到期 / 统一固定周期到期**，自动账单、到期短信 / 小程序消息催缴
- 会员档案、会员编号自定义、会员通讯录（权限控制，可隐藏手机号）、批量导入导出
- 电子会牌（电子会员证）、证书查询核验
- 分支机构管理：党支部、秘书处、专业委员会分组管理会员FastAdmin

### 2. 活动管理

- 活动发布、海报、报名表单、人数限制、图文直播
- 小程序扫码核销签到、自动生成核销码、参会凭证、活动证书
- 活动相册，权限区分：公开 / 仅会员可见
- 高级版：活动接龙、问卷调研、投票选举、活动座位图配置FastAdmin

### 3. 商圈供需（会员资源对接）

会员发布企业产品、采购、求职、供应需求，支持定位、浏览、联系，打造商会内部供需市场FastAdmin

### 4. 资讯与内容运营

新闻公告、政策推送、会员风采展示、文章附件上传；首页可视化拖拽装修，自定义底部导航、组件布局FastAdmin

### 5. 高级版独有模块

- 商城：商品、订单、运费、快递、自提、购物车
- 电子名片：会员商务名片，对外展示
- 积分体系：入会、参加活动、发布供需、邀请会员获取积分，积分商城兑换
- 可视化数据大屏：会员增长、会费收缴、活动统计图表
- 移动端审核：小程序端直接审核入会申请、活动管理
- H5 公众号端，三端打通（PC 后台 + 小程序 + H5）
- 会员推广裂变：邀请新会员入会奖励机制FastAdmin

### 6. 配套能力

- 意见反馈、匿名建议、消息通知
- 权限：FastAdmin 原生 RBAC 权限，多管理员角色、操作日志
- 存储支持七牛云，图片自动压缩
- 导出报表、会员缴费汇总、活动数据统计

## 🖥️ 部署环境

- PHP：7.4
- MySQL：5.6 ~ 8.0（InnoDB）
- 服务：Nginx/Apache，推荐 Linux 宝塔面板
- 部署流程：先装好 FastAdmin 框架 → 后台插件市场离线 / 在线安装沃德商协会插件 → 导入 uniapp 源码编译微信小程序（高级版再编译 H5）→ 配置微信支付、短信、存储、小程序 appidFastAdmin
